# SCORE: Standard Operating Procedures (SOP) & Partitur Alur Kerja Asterisk

Partitur alur kerja standar pergerakan simfoni (*movements*) untuk setiap skenario pekerjaan pada repositori **Asterisk**:

---

## 1. Workflow Pengerjaan Frontend Web (`apps/frontend`)
**Lead Instrument: VIOLINIST & ARTIST**

```text
[Analisis Referensi Desain / Mockup FigCraft]
        │
        ▼
[Buka Skill: design-taste-frontend & responsive-craft]
        │
        ▼
[Buka File Role: .agents/orchestra/VIOLINIST.md]
        │
        ▼
[Definisikan Token Desain Swiss & Tailwind CSS 4 Classes]
        │
        ▼
[Bungkus Field Sensitif dengan useShowingMode Hook (Ctrl+Shift+S)]
        │
        ▼
[Implementasikan Komponen React / Halaman Astro secara Utuh (Full Output)]
        │
        ▼
[Uji 2 Tampilan: Desktop Lapang vs Mobile Cascading Dropdown]
```

1. **Anti-Slop Design:** Terapkan standar Swiss Modernism (Obsidian, Amber, Tangerine, Charcoal, White Shell) dari kanvas FigCraft.
2. **Showing Mode Mandatory:** Setiap badge, credential item, atau URL port wajib memiliki fallback sensor `••••••••••••`.

---

## 2. Workflow Pengerjaan Backend API (`apps/backend`)
**Lead Instrument: CELLIST & PERCUSSIONIST**

```text
[Rancang Skema Relasional Drizzle ORM (13 Tabel PostgreSQL)]
        │
        ▼
[Buka File Role: .agents/orchestra/CELLIST.md]
        │
        ▼
[Terapkan Migrasi Drizzle & Seed Data Tenant]
        │
        ▼
[Buat Endpoint Elysia dengan Validasi Input TypeBox (t.Object)]
        │
        ▼
[Pasang Middleware Masking Showing Mode (Header X-Asterisk-Showing-Mode)]
        │
        ▼
[Catat Operasi Baca/Tulis Credential ke Audit Log]
        │
        ▼
[Export Type App = typeof app untuk Konsumsi Eden Treaty]
```

1. **Type-Safety End-to-End:** Selalu export `type App = typeof app` agar tim frontend mendapatkan autocomplete langsung.
2. **Zero Plaintext Secret:** Password database dan token master wajib melalui enkripsi AES-256-GCM.
